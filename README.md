# 🎮 Split/Second - Multiplayer Mod by zhabi_
Enhanced multiplayer support through Steam.

![Steam](intro.gif)

## ✨ Features
- In-game overlay chat (ImGui-based)
- Automatic version check
- Steam-based multiplayer integration
- Displays the number of online players
- Simple drag-and-drop installation
- Displays current game status in Discord via Rich Presence (Beta)
- Compatible only with [Split/Second – DLC Pack by elysium](https://steamcommunity.com/sharedfiles/filedetails/?id=2095797546)

## 📦 Installation
1. [Download](https://github.com/d-zoar/coordinator_SS/releases/download/v1.0/SS_Multiplayer_1.0.zip) the latest release from the Releases page.
2. Install the required DLC Pack:  
   https://steamcommunity.com/sharedfiles/filedetails/?id=2095797546
3. Extract the downloaded archive into your Split/Second game directory.
4. Launch the game from SplitSecond folder.
5. The multiplayer module will initialize automatically.
6. In the main menu, select the Steam option.
7. Enjoy the game.

## ⚠ Requirements
- Steam client must be running
- Split/Second (Steam version)
- DLC Pack by elysium
- Windows 7 / 10 / 11
- [Visual C++ Redistributable 2015–2022 (x86/x64)](https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/)

## ❗ Troubleshooting
### ❌ Failed to initialize Steam
Make sure:
- Steam is running
- You are logged in

### ❌ Required DLC Pack missing
Install the DLC Pack:  
https://steamcommunity.com/sharedfiles/filedetails/?id=2095797546

## 🐞 Known Bugs
> These issues are currently unresolved. Use at your own risk.

- The game may hang permanently if the connection to Steam services is lost.  
  In such cases, the game must be closed via Task Manager.
- Steam initialization failure can prevent the mod from loading.
